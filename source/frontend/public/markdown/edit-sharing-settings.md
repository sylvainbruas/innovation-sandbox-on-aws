---
title: Edit Sharing Settings
---

Control whether the lease owner can share this lease with other users and groups.

---

## Allow owner to share lease

When enabled, the lease owner can add or remove user and group assignments from the Assignments tab. When disabled, only Admins and Managers can manage assignments.

---

## Important notes

- Only **Admins and Managers** can change this setting.
- Toggling this setting off does **not** revoke existing access. Previously assigned users and groups retain their access.
- This setting is only visible when the global **Lease sharing** feature is enabled.

For more information, see [Managing leases](https://docs.aws.amazon.com/solutions/latest/innovation-sandbox-on-aws/manager-guide.html#manage-leases).
