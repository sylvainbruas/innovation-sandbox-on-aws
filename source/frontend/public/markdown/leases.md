---
title: Leases
---

View and manage sandbox account leases. A lease is a temporary assignment of an AWS account to a user with defined budget and duration limits.

---

## Tabs

**All leases**: All leases you can access. Admins and Managers see all leases across the organization.

**My leases**: Sandbox accounts that you own.

**Shared with me**: Sandbox accounts that others have shared with you directly or via group membership.

---

## Admin and Manager actions

**Assign lease**: Create leases directly for other users without requiring approval. Choose any template (public or private) and specify the user's email address.

**Freeze**: Temporarily suspend user access while preserving account resources.

**Terminate**: End a lease and initiate account cleanup.

**Unfreeze**: Restore user access to frozen leases.

Select a lease name to view details and edit settings.

For more information, see [Managing leases](https://docs.aws.amazon.com/solutions/latest/innovation-sandbox-on-aws/manager-guide.html#manage-leases).

---

## Lease states

View current lease status to understand account lifecycle stage.

For status details, see [Lease states](https://docs.aws.amazon.com/solutions/latest/innovation-sandbox-on-aws/manager-guide.html#understand-lease-states).
